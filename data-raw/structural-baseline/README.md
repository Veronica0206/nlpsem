# Phase C structural baseline

This is the historical 688-model snapshot from nlpsem 1.0.0.9002, whose fitting
source is preserved at commit 31f3d61bb256b12b9ec1b345dc364c8680925fe6.
The snapshot was recompressed without changing its deserialized contents.
`provenance.json` records both hashes, the source revision, generator hash, and
baseline environment. The companion input fixture contains the first 200 rows of
the already shipped RMS_dat example data, with the time rebaselining and covariate
standardization performed by the existing test helper,
all 688 call specifications, and the complete resolved starting values captured
from the Phase C public wrappers, including mixture class-weight coefficients.

From the repository root:

```sh
Rscript -e 'source("data-raw/snapshot_models.R")' . test-results/model-structures.rds . replay data-raw/structural-baseline/phase-c-1.0.0.9002-inputs.rds
Rscript data-raw/test_structure_comparator.R
Rscript data-raw/compare_model_structures.R data-raw/structural-baseline/phase-c-1.0.0.9002.rds test-results/model-structures.rds
```

Create `test-results/` before running these commands. The GitHub full fitting
workflow runs them automatically and retains their logs.

The replay gate exercises the current public wrappers and model builders with
identical inputs. Automatic initialization is not rerun by this gate: it includes
clustering, multinomial fits and nonlinear knot selection that can produce
different starts on different numerical platforms. Those procedures remain
exercised by the ordinary and full numerical regression suites. An automatic
688-model snapshot can still be generated by omitting the replay arguments.

The input fixture was captured by running the Phase C source on the recorded
local platform. Capture mode requires its 688 canonical structures to be
**exactly identical** to the preserved historical snapshot before it writes the
inputs. This verifies the inputs' historical correspondence without replacing or
normalizing the baseline. To reproduce the capture with a verified Phase C
checkout, use:

```sh
Rscript -e 'source("data-raw/snapshot_models.R")' /path/to/phase-c-checkout test-results/phase-c-capture.rds . capture test-results/phase-c-inputs.rds data-raw/structural-baseline/phase-c-1.0.0.9002.rds
```

Replay additionally checks that the stored call specifications match the complete
grid and that each public wrapper records the exact supplied starting values as
user-provided inputs. A replay result therefore measures construction agreement,
not cross-platform equality of automatic starting-value estimation.

The 1.0.0.9003 comparison explicitly permits the reviewed split of a shared
ADD1 matrix into outcome-specific, identical constants for the equal-wave cases
in this historical grid. Their dimensions, values, free masks, labels, and
per-outcome algebra references remain checked exactly.

To accommodate numerical roundoff between macOS arm64 and hosted Linux, numeric
matrix values, lower/upper bounds, and the data checksum may differ elementwise by
at most `1e-10 * max(1, abs(baseline), abs(current))`. This combines a small absolute
allowance near zero with a relative allowance for larger values, including summed
data checksums. Numeric types, dimensions and other attributes, NA/NaN/Inf values,
free masks, labels, formulas, and all fields outside that explicit list remain
exact. ADD1 constants remain exact even within the numerical allowance. All other
differences fail. This allowance does not alter numerical fitting-reference
tolerances.

The comparator also permits the previously reviewed longitudinal mediation M-X
residual starting covariance correction, with exact checks on its named cells
and the unchanged residual diagonal starts. The final 1.0.0 review additionally
permits two exact derived reporting-formula corrections (`Yslp_m` and
`Ychg_bl_m`) for covariate-bearing random-rate EXP/JB change score models. Their
last mean factor now includes its covariate-induced deviation from the expansion
point. Both formulas must match the specified transformation together; fitting
equations, all other algebras and all matrix structure remain checked.

The comparator requires all 688 model identifiers and separately reports exact
matches, each approved change, roundoff alone and approved changes with roundoff.
It also reports the largest accepted absolute and scaled
numeric discrepancy. Its self-tests reject missing or misreferenced constants,
meaningful value changes, type/dimension mismatches, incorrect or incomplete
reporting-formula corrections, and unrelated mutations.

The snapshot records historical behavior; it is not an independent statistical
reference. The new review regression tests separately cover distinct mediation
times, zero covariance starts, three/four outcomes, unequal/reordered schedules,
and numerical inference. Those tests assert mathematical properties and expected
values, including cases absent from the historical grid. Do not replace the
baseline simply to hide a failed comparison.
