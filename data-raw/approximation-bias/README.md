# Approximation bias on generated data

The help of `getSimData()`, `getLCSM()` and `getTVCmodel()` illustrates estimation errors associated with two
fitting approximations in particular generated samples. `run_approximation_bias.R` produces those numbers, and
`results-e1dfb76/` holds the run they are taken from.

```sh
Rscript data-raw/approximation-bias/run_approximation_bias.R <new-output-dir> [cores=1] [source-dir=.]
```

## Design

One data set of 5,000 persons per model, generated by `getSimData()` with its default values (ten yearly
occasions with jittered interior occasions, seed 2026), is fitted by the matching model (CSOLNP, `tries = 3`,
fitting seed 20191029). To examine the contribution of the approximation, each data set is also rebuilt so that the curves follow
the construction the fitted model assumes; growth factors and residuals are the same in every arm of a model.

| Arm | Each person's curve |
|---|---|
| `exact` | the growth curve at the person's own growth factors, as `getSimData()` generates it |
| `taylor` | the curve expanded to first order in the growth ratio or knot around its mean, as a model with a random ratio or knot is fitted |
| `midpoint` | each interval's change as the rate at its midpoint times its length, as a latent change score model integrates its rates |
| `midpoint_taylor` | both, the construction a latent change score model with a random ratio assumes |

An error that decreases in a matched arm supports a contribution from that approximation in this generated
sample. This comparison does not estimate repeated-sampling bias or exclude numerical and sampling effects.
The controls involve neither
approximation: the linear and quadratic growth curve models, the quadratic latent change score model (its
midpoint rate is exact for a quadratic curve), and the fixed-ratio negative exponential growth curve and TVC
models (`LGCM_LIN`, `LGCM_QUAD`, `LCSM_QUAD`, `LGCM_EXP_f`, `TVC_d3_EXP_f`). Fixed-ratio negative exponential
and Jenss-Bayley latent change score models are not controls: they keep the midpoint error. One data set per
model gives a single estimate with its standard error (the `z` column is the estimate minus the true value,
divided by the standard error); it is not a replicated study of bias or coverage.

## Results (commit e1dfb76)

All 29 fits reach status 0 with a positive-definite Hessian and complete standard errors (`fits.csv`).
Observed relative estimation errors quoted in the help, with z in parentheses (`estimates.csv`):
the historically named `relative_bias` column is `(estimate - truth) / abs(truth)` for one sample.

| Model | Estimate | `exact` | Matching construction |
|---|---|---|---|
| LGCM, negative exponential, random ratio | `mueta1`; mean of the ratio | -0.5% (-3.4); -0.7% (-2.8) | `taylor`: all means within 1.4 SE |
| LGCM, Jenss-Bayley, random ratio | `mueta2` | +1.1% (+5.7) | `taylor`: all means within 1.4 SE |
| LGCM, bilinear spline, random knot | means | all within 1.3 SE | |
| Multivariate, negative exponential, random ratio | ratio of the second outcome | -1.0% (-4.1) | `taylor`: all means within 1.1 SE |
| TVC, `decompose = 1`, negative exponential, random ratio | TVC effect `kappa` | +10.1% (+4.1) | `taylor`: +3.4% (+1.5) |
| | mean of the ratio | -2.4% (-4.8) | `taylor`: -0.5% (-1.0) |
| TVC, `decompose = 3`, negative exponential, random ratio | TVC effect `kappa` | +5.2% (+7.6) | `taylor`: +0.7% (+0.9) |
| | `Y_mueta1` | -2.9% (-8.5) | `taylor`: -0.4% (-1.1) |
| LCSM, negative exponential, fixed ratio | `mueta1` | +1.6% (+10.3) | `midpoint`: -0.1% (-0.7) |
| LCSM, Jenss-Bayley, fixed ratio | `mueta2` | -2.3% (-11.9) | `midpoint`: +0.0% (+0.1) |
| LCSM, negative exponential, random ratio | `mueta1` | +1.1% (+7.4) | `midpoint_taylor`: -0.0% (-0.2) |
| LCSM, Jenss-Bayley, random ratio | `mueta2` | -1.2% (-6.3) | `midpoint_taylor`: +0.1% (+0.4) |
| | covariance of `eta2` and the ratio (`psi2g`) | +39.0% (+3.9) | `midpoint_taylor`: +8.3% (+0.8) |

In these random-ratio latent change score examples the two approximations move the means in opposite
directions: with only the midpoint rule matched (`midpoint`), the Taylor expansion alone gives -0.6% (-3.9)
on `mueta1` and +1.1% (+6.0) on `mueta2`; with only the expansion matched (`taylor`), the midpoint rule alone
gives +1.6% (+10.8) and -2.2% (-11.7). The `psi2g` discrepancy is smaller with the midpoint rule matched
(+16.4%) than with the expansion matched (+31.3%), suggesting a larger midpoint contribution in this example.

The effect of the TVC baseline on the slope (`betaTVC1`, +19% to +21%, z about 3) is the same in the `exact`
and `taylor` arms of both TVC models: it is this data set's draw (its sample value is 0.219 against a true
value of 0.188), consistent with sampling variation rather than the Taylor expansion. The controls (`LGCM_LIN`, `LGCM_QUAD`, `LGCM_EXP_f`, `LCSM_QUAD`,
`TVC_d3_EXP_f`) have no estimate beyond 3 SE.

`run-info.txt` records the commit, the R, OpenMx and package versions, the seeds and the run time.
